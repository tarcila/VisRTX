## Generated adaptations

For this project, the generated numeric data is conservatively treated as an
adaptation and distributed under CC BY-SA 4.0, not the software's BSD license.
This is the chosen packaging policy, not a claim that every numerical result
necessarily qualifies as copyrightable Adapted Material in every jurisdiction.

`tables.h` contains the unchanged 128-knot Hermite, spectral fallback and RGB
conversion values from the qualified principled-volume calibration experiment
(`.scratch/principled-volume-calibration/data/lut_data.cuh`, generated by its
`compare_lut.py`). The unused 1024-knot comparison table was removed and C++/CUDA
storage declarations were adapted. Modifications/computations:

- Linear interpolation of the CIE 1931 observer data.
- Planck spectral-radiance integration over 360–830 nm using 0.25 nm quadrature.
- Fixed normalization using a unit-visible-band-radiance D65 reference.
- Tabulation of log-XYZ and derivatives with respect to log temperature at
  128 knots over 300–100000 K.
- Spectral fallback coefficients, RGB conversion constants, and float32 encoding.

`reference.txt` is an independent numeric adaptation generated by
`tools/principled_volume/blackbody_reference.py` directly from the pinned input
CSVs (not by evaluating `tables.h`). It records 0.25 nm spectral quadrature and
the same fixed D65 normalization/gamut convention at sampled temperatures.
Qualification expanded its knot/interior, seam, cold-tail and extreme-temperature
probes. Cold-tail gamut restoration forms the dimensionless Y scale before
multiplication to avoid intermediate underflow. These changes do not modify the
original CIE CSVs or the production table entries. The generated reference data
is also distributed under CC BY-SA 4.0.

The FP32 preview additionally derives a 64-knot log-XYZ/Hermite lookup over
100–300 K at runtime from the spectral coefficients in `tables.h`. Its generated
numeric values are treated under the same CC BY-SA 4.0 adaptation policy. The
runtime construction does not change the original CSVs or the entries in
`tables.h`; the construction and interpolation code remain separately authored
software.

Quality additionally derives a 256-knot log-XYZ/Hermite lookup over25–300 K
using log-sum spectral integration. Its generated values follow the same
CC BY-SA 4.0 adaptation policy. The source evaluator reconstructs XYZ in
binary64 and retains spectral fallback outside its prepared lookup envelope.
No original CIE data or entries in `tables.h` are changed.

These adaptations were generated for the VisRTX principled-volume experiment.
They are not original CIE publications. No endorsement by CIE is implied.
The generation algorithm and tests are separately authored software; this notice
does not relicense the entire software project or unrelated files.

## Redistribution checklist

- Include this attribution notice, `LICENSE.md`, and applicable source metadata
  with redistributed datasets/generated tables.
- Keep the CC BY-SA identifier and attribution pointer in generated headers.
- Identify additional modifications when distributing changed data.
- Include these data notices in binary distributions embedding the tables;
  retaining them only in a source checkout is insufficient packaging.
- Do not label the data as BSD-only or add restrictions inconsistent with its
  license. Preserve any supplied copyright/license/disclaimer notices.

The RTX install rules install these notices and source metadata with binary
packages embedding the tables. This checklist is not a substitute for the
license terms.
